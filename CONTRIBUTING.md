# Contribution Guidelines

## Code of Conduct

Please be respectful and constructive in all interactions.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/pdf-ocr-translator.git`
3. Create a feature branch: `git checkout -b feature/my-feature`
4. Make your changes
5. Test your changes
6. Commit with clear messages: `git commit -m "feat: add new feature"`
7. Push to your fork
8. Create a Pull Request

## Branching Strategy

We use Gitflow:
- `main` - Production releases
- `dev` - Integration branch
- `feature/*` - New features
- `bugfix/*` - Bug fixes
- `hotfix/*` - Urgent production fixes

## Commit Messages

Follow conventional commits:
- `feat:` - New feature
- `fix:` - Bug fix
- `docs:` - Documentation
- `test:` - Tests
- `refactor:` - Code refactoring
- `chore:` - Build/dependency updates

## Pull Request Process

1. Update DEVELOPMENT.md with any new process details
2. Ensure all tests pass
3. Ensure code follows style guidelines
4. Request review from maintainers
5. Maintainer performs squash merge to dev
6. Owner merges dev to main for releases

## Questions?

Open an issue or discussion in the GitHub repository.
